# Data Structures and Algorithms in Python

A structured collection of my solutions to Data Structures and Algorithms (DSA) problems using Python. This repository documents my learning journey, problem-solving approaches, and understanding of time and space complexity.

## 🎯 Objectives

- Strengthen problem-solving and logical thinking.
- Learn fundamental data structures and algorithms using Python.
- Understand time and auxiliary space complexity.
- Practice writing clean, readable, and efficient code.
- Build a consistent collection of solutions for coding interviews and technical assessments.

## 🛠️ Language and Tools

- **Language:** Python 3
- **Practice Environment:** VS Code / Google Colab
- **Version Control:** Git and GitHub

## 📚 Topics Covered

### 01. Complexity and Basics
- Finding the maximum and minimum elements in an array
- Finding the second-largest distinct element
- Reversing an array using two pointers
- Checking whether an array is a palindrome
- Finding a pair with a given sum in a sorted array
- Removing duplicates from a sorted array in place

### 02. Strings
- Reversing a string using backward traversal

## ⚙️ Approach to Problem Solving

For each problem, I aim to:

1. Understand the problem statement and identify edge cases.
2. Develop a logical approach before writing code.
3. Implement the solution in Python.
4. Test the solution with different inputs, including edge cases.
5. Analyze time complexity and auxiliary space complexity.
6. Improve the solution where possible.
